# Arc creator and meme token launchpad

**Status: research and product specification only. No product code, Studio app, deployed contracts or transactions.**

**Final decision: BOTH v3 and v4.** Creators choose their launch path; each path has a different compatible feature set. One token has one canonical path. The complete initial product must support both, even though engineering proceeds in stages.

The product combines token launching and trading with transparent collected-fee accounting, community USDC budgets, funded creative work and contributor payments. This is a positioning hypothesis, not a claim that Arc lacks launchpads.
