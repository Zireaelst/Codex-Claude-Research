# MCP configuration examples

Prefer the supported CLI commands in the package README. These files are reviewable examples, not proof of installation. Claude project config is `.mcp.json`; merge the `base-docs` entry while preserving other servers. Codex config uses the shown TOML table; its CLI manages the client configuration. Do not copy a full example over an existing settings file. No credentials are required for public docs search. Workspace trust, administrator policy and client restart may affect availability. Verify with an actual search/read in the new session.
